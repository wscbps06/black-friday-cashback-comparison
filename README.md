## Common Pitfalls to Avoid

A few ways people accidentally leave money on the table:

- **Using a coupon code from a different site.** Some retailers void cashback if you apply a code that wasn't surfaced through the cashback platform. When in doubt, let TopCashback's coupon section surface codes first.
- **Opening the retailer in another tab before clicking through.** The click-through has to be the last action before checkout for the tracking cookie to register. If you already had the retailer open, close the tab, click through from TopCashback, then re-add your items.
- **Forgetting that returns cancel cashback.** If you return an item, the cashback on that item is reversed. Budget accordingly.
- **Assuming the cashback rate is fixed.** Rates change weekly during the holiday window. A 4% rate on Monday can become 12% on Friday. Check before each big purchase.
